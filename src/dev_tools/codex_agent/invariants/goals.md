Интерфейс
Я отправляю задачу одному кодекс агенту и прощу вызвать: `dev-tools codex-agent start-flow"
Он получает первую свою инструкцию и создает локальный блок файлов для данного флоу.
В инструкции Human Facing агенту будет сказано, создать агента и дать ему инструкцию для получения промпта.

И далее система должна организовать всю необходимую работу.
Пользователь может поменять некоторые настройки локально.


events.yaml - append only. only current flow
state.yaml - current flow state.

Не усложняем модели correlation_id, last_event_id и другими мало полезными полями на текущем этапе.
